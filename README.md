This repository holds a Salesforce implementation for SparkNest, whose operations team used to manage customer enquiries and support cases through spreadsheets, WhatsApp and email. It includes a data model for enquiries and the products customers ask about, role-based security for the Sales and Support teams, flows and Apex that automate follow-ups and closing, a REST API that the SparkNest website can call to submit enquiries, reports and a dashboard for management, and an Agentforce agent that answers customers' enquiry status questions. The code is a Salesforce DX project and its tests pass with 85% coverage
